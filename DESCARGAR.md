# Descargar Zielo Server Launcher

[Descargar la última versión para Windows](https://github.com/ZielCL/zielo-launcher-releases/releases/latest)

En Assets, descarga el archivo `ZieloServerLauncher_vX.Y.Z_Windows_x64.zip`, extrae su contenido y abre `ZieloServerLauncher.exe`.

Para actualizar, detén el servidor y cierra el launcher antes de sustituir el programa. Conserva tu carpeta de datos, mundos y configuración.

Las versiones anteriores a 11.12.2 requieren una primera actualización manual. Desde 11.12.2 puedes buscar y descargar futuras actualizaciones desde el launcher; la sustitución del programa sigue siendo manual.

Este repositorio contiene descargas e instrucciones. El desarrollo del código permanece privado.
